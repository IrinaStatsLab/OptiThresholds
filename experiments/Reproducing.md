# Reproducing experiments in the paper

This folder contains the ipynb notebook files to reproduce the experiments provided in our manuscript. Each notebook file is self-contained and provides detailed guides to reproduce the results provided in the paper.

## Experiments in the main paper

- `Simulations.ipynb`: simulations with $n=200$ distributions (additional $n=50, 100$ results for supplementary)
- `Real-data.ipynb`: CGM data experiments with non-diabetes and type 1 diabetes datasets
    - These two datasets are available through [Awesome-CGM](https://github.com/IrinaStatsLab/Awesome-CGM)
- `Real-data-ai-readi.ipynb`: AI-READI CGM data experiments (spanning non- to early type 2 diabetes)
    - AI-READI data processing guide is provided in [../data/AI_READI_processing_guide.md](../data/AI_READI_processing_guide.md)
    - For this file to run, you need to set R_HOME to use the Python library `rpy2` library and use R packages `ClarkeTest` and `WR`.

- The figures for real data experiments are generated by `tools/figure_creation.R`.

## Experiments in the supplementary material

Additional results include the comparison with naive thresholds provided in the supplementary material, as well as the screeplots of the real datasets.

- `Screeplot-real-data.ipynb`: Generate screeplots of the real CGM data experiments, suggesting $K=4$ thresholds are enough
- `Real_loss_comparison.ipynb`: loss comparison script
- `Real-data-ai-readi-naive-thresholding.ipynb`: additional downstream predictive performance comparison with naive thresholds.
